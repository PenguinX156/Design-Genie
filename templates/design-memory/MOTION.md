# Motion

Record the purpose, trigger, duration, easing, reduced-motion behavior, and performance budget for each signature interaction. Prefer static presentation when motion adds no value.

For reference-driven 3D, also record the still, mesh/geometry source, UV texture source and license, camera/light/material setup, fallback, expected first-frame match, and probe paths for rest and rotated states. Check first-input loading, WebGL failure, keyboard input, mobile framing, and clipping before approval.
