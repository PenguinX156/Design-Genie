# Visual critique rubric

Evaluate each dimension from 1 to 5 with screenshot or interaction evidence. The score is descriptive, not an automatic pass.

| Dimension | Ask |
| --- | --- |
| Product fit | Does the surface convey the intended trust, energy, and information density? |
| Hierarchy | Is the primary action and reading order obvious at each width? |
| Typography | Is the type purposeful, legible, and consistent? |
| Composition | Are balance, alignment, rhythm, and whitespace controlled? |
| Content and imagery | Are claims specific, assets suitable and licensed, and focal points or crops intentional? |
| Identity | Is there a distinct but coherent visual language? |
| Interaction | Do controls and their states work with mouse and keyboard? |
| Responsive | Are mobile and tablet layouts intentional, not merely squeezed? |
| Motion | Does movement communicate state or story without distraction? |
| Accessibility | Are contrast, semantics, focus, labels, and reduced motion addressed? |
| Performance | Are large assets, animation, and rendering costs justified? |

Severity: **critical** blocks a primary task or makes content unusable; **high** damages comprehension or key access; **medium** weakens polish or consistency; **low** is local detail. An anti-generic finding needs a reason tied to the selected direction, not a forbidden-pattern count.

For a prominent visual element, review its complete path: initial view, active interaction, and fallback. For 3D, inspect the model from at least one rotated view and compare the placeholder with the first live frame. A screenshot cannot show whether motion stutters; verify it in a browser and use probe frame intervals as supporting evidence.
