# Typography

- Display: Libre Bodoni Regular (SIL OFL), self-hosted via `@fontsource/libre-bodoni`; oversized, tight tracking, about 0.93 line height. Georgia fallback.
- UI/body: Space Grotesk Regular and Medium (SIL OFL), self-hosted via `@fontsource/space-grotesk`; uppercase UI labels with wide tracking, 16–20px body. Sans-serif fallback.
- Desktop hero 7–9vw, maximum 160px; mobile about 14vw. Line length stays below about 42ch. Font CSS uses `font-display: swap`.
