# Components

- Site header: wordmark, desktop anchors, mobile disclosure with `aria-expanded` and Escape dismissal.
- Underlined text links: shared hover/focus treatment and arrow SVG.
- Study selector: three native buttons, selected state via `aria-pressed`, visible keyboard focus; updates description and 3D geometry.
- Sculpture stage: accessible region, drag input, motion pause and WebGL fallback, explicit rotation hint.
- Process strip: three editorial labels, not links.

Implementation: `index.html`, `src/main.js`, `src/sculpture.js`, `src/style.css`.
